# Taleb Bouamatou — Portfolio

A lightweight, responsive portfolio site built with HTML, CSS and JavaScript. It includes an English/French language switch and alternating black and ivory sections. The profile photo is a transparent PNG cutout. Official programming and software marks load from the Devicon and Simple Icons CDNs. Technologies without a suitable verified mark are shown as text labels instead of invented or broken logos.

## Preview locally

Open `index.html` in a browser. The site has no build step or required packages.

## Publish with GitHub Pages

1. Create a repository named `talebmedbouamatou.github.io` under the GitHub account `talebmedbouamatou`.
2. Upload the contents of this folder to the root of the repository.
3. In the repository, open **Settings → Pages** and select deployment from the `main` branch and `/ (root)`.
4. GitHub Pages will provide the public site at `https://talebmedbouamatou.github.io/` after deployment.

The portfolio links to the GitHub profile, LinkedIn profile and email address. It does not include phone numbers or a downloadable CV. Project summaries are public; source code is not included.
